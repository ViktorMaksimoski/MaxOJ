<TaskBody>
    Your task is to create a permutation of numbers $$1, 2, ..., N$$ that has exactly $$K$$ inversion.

    An inversion is a pair $$(a, b)$$ where $$a < b$$ and $$p_a > p_b$$, where
    $$p_i$$ denotes the number at position $$i$$ of the permutation $$p$$

</TaskBody>


<Section title="Влез">
    Тhe only input line has two integers $$N$$ $$(1 \leq N \leq 10^6)$$ and $$K$$ $$(1 \leq K \leq \frac{N\cdot(N-1)}{2})$$.
</Section>

<Section title="Излез">
    Print a line that contains the permutation. You can print any valid solution.
</Section>
